# WealthBoard mobile-friendly join display

When you join, you will see a short **Welcome!** message and **Wealth in chat** beneath it.

Open chat to see the three richest players. Each player’s complete name appears on its own ranked line, with their balance underneath. Longer names can wrap naturally instead of disappearing beyond the edge of the screen.

Use `/leaderboard` to reopen the full server leaderboards. `/baltop` shows wealth, and `/mctop` shows mcMMO rankings through the existing server commands.

If there are no recorded balances yet, the welcome message says **Go earn!** and chat explains that the board is empty.

This display works the same way for Java and Bedrock players. It does not create a permanent sidebar or shorten player names.

## Mobile check after installation

1. Leave and rejoin the server.
2. Check that the short welcome message fits your screen.
3. Open chat and confirm that each ranked name and balance is readable.
4. Try `/leaderboard` to reopen the full boards.
