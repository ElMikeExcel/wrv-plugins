# Spawn Shop integration

Use the current live DeluxeMenus Spawn Shop file, not an older repository copy or generator. Back it up, recheck its checksum before writing, choose an actually free slot, and preserve all unrelated entries including both Death Protection products.

The supplied item template deliberately has no slot. Insert it only after selecting a free live slot. Both clicks call exactly one `mobveil buy <player>` console command; the plugin opens its own review and owns the price, withdrawal and delivery. Never add a second withdraw/give action. ExcelShops 0.1.5 cannot create the required tagged PotionMeta item directly.

Verify the native review and Back/close behavior on Java and Bedrock/mobile. A YAML parse or server startup does not prove client usability. Publication/installation and website status must be reported separately.
