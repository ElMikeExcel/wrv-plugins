## Rig (Paper 26.3-235, Moon's lifecycle fixture, synthetic player) — 78 checks, 0 failed, SEVERE 0

Probe037 (`rig/evidence/probe037-result.txt`, server log
`rig/evidence/boot4-latest.log`, console `rig/evidence/boot4.console.log`).
The fixture wand knows 8 spells; the loadout seeds page 1 full (slots 0–6),
so every target was read live from the model. Proven at the event level:

- **Click-carry, bar → bar:** pickup Mend's icon, place on Heal's slot →
  both events cancelled, loadout swapped, `loadouts.yml` **on disk** holds
  Mend at the new slot, and a wand stow/re-draw paints Mend there.
- **Drag-off removal:** carry Heal's icon to the grid → Heal leaves the
  loadout, stays learned, removal counter and confirmation fire.
- **Mike's Ward repro:** Cure granted, taken off the bar, its icon placed in
  the inventory grid (slot 20) → grid pickup lifts (counter), place on the
  bar slot writes it back; file on disk agrees.
- **Mike's Wolf repro (all-spells shape):** the same grid-carry dialect with
  Feed from grid slot 21 → written to its bar slot. (The fixture's spell set
  is closed — no wolf/fling exists to grant — so a second known spell stands
  in; the event dialect is identical, and the off-bar intent matrix is
  unit-pinned in DragWritePlanTest.)
- **Real drag event, bar → bar:** an InventoryDragEvent with Mend's icon on
  the cursor over Boon's slot → cancelled, loadout swapped.
- **Non-spell protection:** dirt placed onto a spell icon's slot → event
  cancelled, loadout unchanged, icon-protection counter fired, dirt unharmed.
- **Confirmation labels:** the action-bar line for the Mend write was captured
  in the client's packet backlog reading "Bar 1 · Slot 2: mend"; the drag-off
  line "Heal off your bar" likewise. (Packet flush into the rig's embedded
  channel lags phases behind, so message verdicts were judged on the
  session-wide backlog — 120 captured strings — not on per-phase drains;
  runs 1–3 in `rig/evidence/` show the lag and the probe's corrections. The
  Bar 2 label could not be staged live: the fixture's page flip does not take
  through setCurrentHotbar or a synthetic sneak event, so "Bar 2 · Slot 1" is
  pinned by BarPositionTest instead.)
- **0.3.6 regression (exit sweep):** foreign item in the exit column is swept
  to the stored inventory on open and back to the real inventory on close;
  full-storage open is refused with every seeded item preserved (in this
  fixture only one page slot was free to seed — the 0.3.6 rig's fuller
  seeding stands as that suite's record, and ExitSweep itself is
  byte-identical); a mid-open give survives the close; the sweep's chat line
  reached the client (backlog).
- **Kill switch:** `drag-write.enabled: false` written into the rig config +
  `/wandbars reload` → summary reports "drag-write OFF", and an unarmed icon
  pickup is cancelled with the 0.3.6 signpost counter at 1 and the signpost
  line itself in the client backlog. 0.3.6 semantics restored by config alone.
- Boot: plugin version 0.3.7 confirmed from the running server; **SEVERE 0**
  across the whole run.
