# Build and tests
Use reviewed JDK 25 with --release 21. Invoke `bash build-and-test.sh` with JAVA_HOME, CP_MAIN (complete caller-supplied reviewed dependency classpath) and OUTPUT_DIR (new nonexistent directory outside this packet). Script downloads nothing, starts no server, deletes nothing, compiles full source, copies archived packaged resources, runs core tests and the timer harness. Output is classes/tests only, not an installable JAR.

Dependency families include Paper API, PlaceholderAPI, Vault API, Kyori Adventure/examination, SnakeYAML, annotation APIs, Guava and associated Paper API transitive dependencies. DEPENDENCY-INVENTORY.json records exact filenames/hashes present in the prior qualified full-compile classpath reused for this fresh check. This broad classpath inventory is not a claim every JAR was loaded and not a binary redistribution grant. Dependencies must be obtained under their own licenses; this source-only packet does not provide a standalone dependency-complete build or network acquisition instructions.

Old host-specific build scripts and stale version 0.1.5 output naming are omitted, replaced with explicit inputs and no overwrite behavior. No automatic packaging/deployment. For any new deployable artifact separately review dependency provenance, deterministic packaging, full runtime tests and comparison to installed bytes. Historical packaged17 defaults are not current live19 configuration.
