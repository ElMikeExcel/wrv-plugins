- **Source changes by file:**
  - `core/QuitClosePlan.java` — **new, pure logic.** `decide(enabled, usesTapBar, wandPresent, barOpen)` → CLOSE only when all four hold. `enabled` is the existing `join-starts-on-items` switch: the logout close is that policy enforced at the other end of the session, so it shares the switch — no new config key.
  - `core/JoinSweepPlan.java` — **new, pure logic.** `shouldSweep(guardEnabled, sweepEnabled, finalCheck, guardLeft, barOpen, alreadySwept)` → true only at the guard's final check, on a LEAVE verdict, with an open bar, both switches on, and not already swept this join.
  - `QuitCloseHook.java` — **new.** A tiny `Listener` for Paper's `PlayerConnectionCloseEvent` (fired synchronously from connection teardown, BEFORE `PlayerQuitEvent` dispatch and therefore before Magic's quit handling reads the wand's open state for its restore decision — the ordering finding in BUILD-RECORD.md). Resolves the player by UUID and calls `TapBarHook.closeBarAtExit(p, "connection close")`. Registered in its own try/catch in `ExcelWandBars.onEnable` (house isolation for platform-optional hooks): without the event, the quit-handler belt + join guard remain.
  - `TapBarHook.java` — new `closeBarAtExit(Player, String)` (shared by the hook and the belt): applies `QuitClosePlan`, closes via the same `w.closeInventory()` `stop()` uses, verifies the bar is down, counts `quitCloses` / `quitCloseBlocked`, logs the "Quit close:" line. `onQuit` calls it first (belt for `logout_delay > 0`) and also clears the new per-join sweep set. `onJoin` schedules the 160-tick check as `joinGuardCheck(p, true)`; the 1-arg `joinGuardCheck(Player)` remains as the probe entry delegating with `finalCheck = false`. The 2-arg overload's LEAVE branch consults `JoinSweepPlan` and, when it holds, marks the join swept, runs the existing `ExitSweep.run(...)` in a try/catch (one warning on failure, mirroring tryOpen), counts `joinSweeps` / `joinSweepMoved` / `joinSweepLeft`, and returns `leave (bar open; join sweep ran)`. `counters()` gains the `join-sweeps …` and `quit-closes …` segments.
  - `ExcelWandBars.java` — registers `new QuitCloseHook(tapBar)` in its own try/catch immediately after the tapBar registration block; nothing else.
  - `work/shipped/plugin.yml` — version 0.3.11 + a "New in 0.3.11…" description sentence. `work/shipped/config.yml` — **unchanged** (byte-identical to 0.3.10's): no new keys; the packet is jar-only.
