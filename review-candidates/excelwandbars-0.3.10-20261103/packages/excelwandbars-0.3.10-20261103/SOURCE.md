- **Source changes by file:**
  - `core/CooldownTagPlan.java` — **new, pure logic.** `shouldTag(ms, thresholdSeconds)` = strictly over the threshold (exactly 60,000 ms at 60 s → no tag; 60,001 → tag); `secondsShown` ceilings; `format` m:ss (240 → "4:00", 61 → "1:01", 7 → "0:07", 3600 → "60:00"); `suffix` = `" · " + format`; `annotated` / `hasOurSuffix` / `stripSuffix` pattern fallback (last " · " followed by digits, colon, two second-digits < 60; strip removes one trailing suffix only).
  - `NameTagHook.java` — **new.** Mirrors `PagerHook`'s shape and discipline. Poll every 10 ticks: standing cleanup first, then render of display slots 0–8 while the wand inventory is open. PDC markers: `cooldown_name_tag` (the spell's original display name, Gson-component-serialized) and `cooldown_name_spell` (spell key, staleness guard). Render captures the current name as base on first annotation and always re-renders from the recorded base (no suffix stacking); refresh appends a gray non-italic suffix component. `sweepNow(Player)` restores the display; `cleanupPlayer` restores marked items in place in the wand's stored inventory, hotbar page contents (all pages but the current one while open; all pages when closed), the real inventory while the bar is closed, and the cursor — never deletes. Events: join (+20/+60 cleanup), InventoryClose MONITOR (+1/+10), PlayerDropItem (restores the dropped copy), quit (LOWEST; steps individually guarded), disable (`sweepAll`). Settings from `cooldown-name-tag`: `enabled` default true, `threshold-seconds` default 60 clamped [0, 3600]; when disabled, no new annotations but the display is swept and cleanup stays active. Fail-soft per player (disable-for-session + restore + one warning).
  - `MagicHook.java` — new `sweepNameTag(Player)` beside `sweepPager`, called at the same three sweep sites (sneak-flip branch, `flipPage`, `flipListPage`).
  - `ExcelWandBars.java` — `nameTag` field constructed in try/catch after the pager block (loadSettings + registerEvents + start + "Cooldown name tag …" info line), `nameTag()` accessor, reload wiring, onDisable stop + `sweepAll`, status-line segment.
  - `work/shipped/config.yml` — new `cooldown-name-tag` section appended with explanatory comments (`enabled: true`, `threshold-seconds: 60`). `work/shipped/plugin.yml` — version 0.3.10 + a "New in 0.3.10…" description sentence. Both parser-verified valid YAML.
