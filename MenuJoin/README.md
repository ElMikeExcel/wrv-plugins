# MenuJoin 1.2.0
Argus's compass plugin, updated by Steve. Gives the menu compass on join and respawn; it does not drop on death and cannot be thrown away; `/compass` gives a new one. Compass identified by PDC key `menujoin:menu_compass` (same as 1.1.0). PAPI placeholder `%menujoin_status%` for the auto-open toggle. Build: `./build.sh`.
