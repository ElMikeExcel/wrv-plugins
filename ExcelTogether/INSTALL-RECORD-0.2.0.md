Mike decisions applied (Oct 16, 2026): a party IS ExcelTogether's group (same thing as the +25% bonus); the invitee must accept with a popup like /tpa; cap 5 per party.
What it does:
- Compass click: right-click a player holding a compass asks "Invite NAME to your party?" first. Bedrock gets a Yes/Cancel form, Java gets clickable [Yes] [Cancel] in chat (/excelparty confirm, /excelparty cancel). Nothing is sent to the other player until Yes. The question lasts 30 seconds, is replaced by a newer compass click, and is dropped if the asker logs off. If the target logged off by the Yes tap, the asker is told and nothing is sent. The invitee still gets the normal 60-second Accept/Decline popup.
- Invite: menu "Invite to party" lists online players (Bedrock form, Java clickable chat list); right-click another player while holding a compass (asks Yes/Cancel first); or /excelparty invite <name>.
- Popup: Bedrock invitee gets a form with Accept and Decline. Java invitee gets clickable [Accept] [Decline] in chat plus an action bar ping. Invite lasts 60 seconds; both sides are told when it runs out. If the Bedrock form cannot be sent, it falls back to the chat panel.
- My party: lists members (leader tag, offline tag) with Invite more and Leave (Leave asks first). Leader can /excelparty kick <name>.
- Bonus: +25% Jobs money and XP now applies when a PARTY member is within 50 blocks (config bonus-mode: party). Strangers nearby no longer count. Set bonus-mode: nearby for the old 0.1.0 behavior, or either.
- Rules: 2 to 5 members; a party that drops to one member ends; leader leaving hands leadership to the longest-standing online member; a disconnected member keeps their seat 5 minutes (offline-grace-seconds) then is removed; invites are stored until accepted so an unanswered invite leaves no party behind; parties live in memory only (a server restart clears them).
- Names: works with Bedrock dot names (type coolgirlkail or .coolgirlkail), nicknames (color codes stripped), case, and unique prefixes; ambiguous names list the matches. Players are shown without the dot. Java chat buttons use the real login name so the click always resolves.
Command name: /excelparty (aliases /eparty, /together). NOT /party, because mcMMO owns /party here (it is in the server command list as "Your mcMMO party"). The menu button also runs /excelparty.
Edge cases covered by tests: full party (at invite and at accept time), invite self, already in your party, already in another party, offline target, target left between pick and tap, inviter left before accept, expiry (exactly 60s valid, 60.001s expired, stale Bedrock Accept tap refused, re-invite after expiry), duplicate invite, cross invites, two invites at once with one seat left, leader leaves, last two members, leader prefers an online successor, kick rules, disconnect grace and rejoin, sweep when everyone disconnects (this caught a real null error, fixed), dot-prefix Bedrock names including a Java and Bedrock twin pair, nicknames with color codes, vanished players hidden from the picker, picker hides players already in parties, compass double tap spam guard, form failure fallback, Cumulus builders (simple, modal, 20-button picker), bonus-mode parsing and decisions, config clamps, plugin.yml/config checks, no teleport or economy calls in the code.
Not included: persistence across restarts, party chat, shared XP beyond the existing +25% Jobs bonus, mcMMO party link, claim sharing, any teleport.
Dependencies (plain words): Jobs required (as 0.1.0). Geyser and Floodgate optional (Bedrock forms). Essentials not needed. No new data files.
