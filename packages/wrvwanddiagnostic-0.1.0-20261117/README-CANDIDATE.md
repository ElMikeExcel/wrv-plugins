# WRV Wand Diagnostic 0.1.0: OFFLINE candidate, not deployed

Separate plugin. Does not replace ExcelWandBars0.3.2 and does not fix/change any gesture. Requires Geyser-Spigot and ExcelWandBars. Built against exact Geyser2.12.0-b1269/Paper cachedAPI, Java21.

Default: owner-uuid blank, capture OFF, no translator registrations until explicit console `wanddiag start`. Config must be set to owner's UUID before a future authorized session. Console-only commands `wanddiag start`, `wanddiag show`, `wanddiag stop`; no player commands. Start requires configured owner online. It cannot select arbitrary names via command.

Capture hard-limited to60seconds based on monotonic time. Every capture checks owner and expiry. Last64 sanitized event records plus fixed enum counters retained. High-frequency AuthInput details appear only on allowlisted flag/input-mode changes; packet count still advances. Quit/expiry/manualstop restore only this plugin's owned translator registrations and save sanitized `last-snapshot.txt`. Snapshot stays in memory after logout; disk copy survives shutdown. Starting another session clears previous memory; final snapshot file replaces previous file. No automatic start/retry.

Captured: relative timing, enum category, safe slot/container/action integer pairs, inputmode/model, protocolnumber, sneak state, Bukkit cancelled status and viewtype. Owner UUID used only in memory/config filter, not snapshot. No packet stringification, item contents/NBT, chat, positions/rotations, entities, IP, device identifiers or credentials. No Geyserdump.

Observe wraps only existing registered translators and forwards the identical original packet exactly once. Absent translator is skipped, never invented. Current categories: MobEquipment, PlayerAuthInput, InventoryTransaction, Animate, PlayerAction, ItemStackRequest, PlayerHotbar if handled, Interact (including OPEN_INVENTORY). It reports observer ownership and whether prior wrapper belonged to WandBars. Does not inspect private callback fields or alter existing WandBars gates. Existing WandBars diagnostic counters should be read separately to correlate final decisions. Generic observation cannot see packets discarded before Geyser translator dispatch; absence here is not complete wire-level proof.

AUTH `a` flag bit order:0SNEAKING,1SNEAK_DOWN,2START_SNEAKING,3STOP_SNEAKING,4MISSED_SWING,5START_USING_ITEM,6PERFORM_ITEM_INTERACTION,7PERFORM_ITEM_STACK_REQUEST,8PERFORM_BLOCK_ACTIONS,9HOTBAR_ONLY_TOUCH. `b` is cached selectedslot. Enum columns inputmode,interactionmodel. SESSION a=protocol,b=Geyser sneak. STATE a=Bukkit slot,b=Bukkit sneak, enum=viewtype. USE a=action,b=slot; enum=transactiontype/trigger (embedded use has trigger in first enum). Other categories are explicit in Observe.java/WandDiagnostic.java.

Safety verification: full compilation passed;21 core/wrapper invariants and19 real packet-class assertions passed (40 total). These include OFF, owner exclusion,64cap,60sexactexpiry,summaryretentionlogout,originalpacketidentity/fieldpreservation,once-onlyforwarding,originalexception/eventloopsemantics. Packet tests use synthetic Unsafe fixtures only; no Unsafe production code. No actual phone or server boot validation performed. Full plugin lifecycle and registry restore behavior still needs a disposable integration test before any live deployment. This is not deployment-ready authorization.

Inventory fallback research: Geyser1269 BedrockInteractTranslator OPEN_INVENTORY opens playerInventoryHolder inside Geyser for normalplayer, or sends vehicleinventory command forvehicle. A Bukkit InventoryOpenEvent alone is not a reliable detection method for the touch3dot button. Any future behavior needs main-thread Magic restore plus safe ordering with Geyser inventoryopen, and item-conservation validation. This candidate OBSERVES ONLY.
