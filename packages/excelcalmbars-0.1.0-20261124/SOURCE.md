Mechanism: combat state from Bukkit EntityDamageByEntityEvent (MONITOR, the fleet D184 pattern); one Netty ChannelDuplexHandler per player connection sees ClientboundBossEventPacket objects before encoding; a bar is an XP bar only on a POSITIVE title match against the Jobs pattern (live locale template), an mcMMO skill-name pattern (the 19 live skill names + "Learning a new skill..."), or an EliteMobs skill-bar pattern (live skills.yml formats over the 11 live EM skill types, incl. the LEVEL UP variant); a never-hold substring list ("inventory protected") belts the ExcelDeathProtection bar. Held packets merge into per-bar state; release rebuilds the bar via ServerBossEvent; REMOVE always passes; death / world change / logout / disable flush cleanly; max hold 120 s. All NMS access is reflection through BossBridge — if the bridge cannot resolve, the plugin reports itself unavailable and gates nothing. Commands: /calmbars status|flush|reload (status is player-form by design). Full mechanism + the three defects the mirror proof caught: BUILD-RECORD.md in this package.
