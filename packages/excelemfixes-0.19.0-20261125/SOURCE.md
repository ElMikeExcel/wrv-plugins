- **What it is:** a change inside the existing **quest-destinations** module (module count unchanged at 22). When a player's tracked or carried quest has no row in the quest-destinations table, its destination is now derived from the quest's current incomplete DIALOG objective — the target NPC's spawn location, read from EliteMobs' own NPC registry. The quest beacon and /questwhere then lead to the person the quest sends you to talk to, and because the current incomplete objective is read each time, the beam follows the current objective as dialogs complete. Table rows keep precedence whenever a row exists (rows encode instance entries EliteMobs' data cannot express). New knob: `derive-dialog-destinations` (default true); false restores the exact pre-0.19.0 behavior. No quest, NPC, or place is known by name — everything is derived from EliteMobs' loaded quest/NPC data, so any content pack using dialog objectives is covered.
