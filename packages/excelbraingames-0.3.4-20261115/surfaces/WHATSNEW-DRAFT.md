## Website What's New entry

**Brain Games: every screen has a Back button** — The Brain Games
menu now takes you back to the Server Menu, and every game board
and question card has a Back button that saves your round and
returns to the game picker — pick up right where you left off.
On the big 9x9 Sudoku board, the eraser now sits with the 6–9
numbers so Back could take its place.
