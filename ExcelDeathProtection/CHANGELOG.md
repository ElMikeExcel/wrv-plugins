# ExcelDeathProtection changelog

## 0.1.0 — October 13, 2026

- First build. Death Protection Potion: drink it and your next death keeps all your items, once. Death is not prevented and XP is not saved.
- Buff shows as the Luck status effect (small clover icon + listed in the inventory screen) on Java and Bedrock; buff state is stored per player and survives relogs and restarts.
- Shop hookup: `/deathprotection buy` (two-tap confirm, Vault charge) for the Spawn Shop menu's console command, plus `/deathprotection status` and admin `/deathprotection give`.
- Price set by Mike: $10,000.
